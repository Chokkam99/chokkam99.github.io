  • Bakes start automatically every month. I make the remediation and promotion decisions for these images: fix and rebake, or defer with a time-boxed exception, and I force an out-of-cycle release when a critical finding lands mid-month. The security team owns the scanners and approves exceptions.

    Read in context

  • A security fix needed a newer database driver. The uploaded package had the right version number but the wrong contents: it was an installer, not the driver. The bake passed, and so did the scan, because both trusted the version. I found it by inspecting what was inside the package, then swapped in the correct artifact. The lesson I took: version-based checks can't catch wrong contents, so assert the contents before promotion.
